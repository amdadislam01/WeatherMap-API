#  WeatherMap API 🌤️

A beautiful weather application with interactive map that displays current weather conditions and forecasts worldwide.

##  Features ✨

- 🌍 Interactive map to select locations
- ☀️ Current weather conditions (temperature, humidity, wind speed)
- 🌈 Weather icons and visual representations
- 📱 Responsive design works on all devices
- 🔍 Search functionality for cities worldwide
- 🗺️ OpenStreetMap integration
- 🌡️ Temperature units toggle (Celsius/Fahrenheit)

##   Technologies Used 🛠️

- OpenWeatherMap API
- Leaflet.js (for interactive maps)
- HTML5, CSS3, JavaScript
- Bootstrap (for responsive design)

##  How to Use 🚀

1. Visit the [live demo](https://amdadislam01.github.io/WeatherMap-API/)
2. Click anywhere on the map or search for a city
3. View current weather information
4. Toggle temperature units as needed
